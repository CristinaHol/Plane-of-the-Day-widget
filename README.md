# Plane of the day Widget
This is a widget for Mac os. It displays a new plane when opened every time. 
## Motivation
The motivation behind this project is to use it as a learning tool to be able to identify different military aircraft. 
My dad and I share plane spotting as a hobby and living close a military base means there is something flying over every once in a while, and rather than shouting out PLANE! I wanted to be able to identify what i was looking at.
## Currently added planes
* F-16
* F-19
* F-22
* C-130
